"Learn to Code" feature blocks: four layouts

Four layouts for the same five callouts, so the layout is the only variable between them. All images, no video. A big lead with four compact thumbnail rows; three cards with the last two on a tinted strip; a hub with one large product image and the callouts around it; and a 2 by 2 of four equal blocks with images large enough to read. Every visual is a stand-in pulled from the existing demo recording, and each one names the asset that will replace it.

1. Lead and list

One callout carries a large image; the rest run beneath as compact rows with square thumbnails. Clearest hierarchy of the three.

Learn to Code

We'll help you build rock solid coding foundations: every core concept, with tons of exercises and projects to practise on.

Errors in plain English

When something breaks, Jiki tells you what went wrong in normal English, not technical jargon.

  • Rewind your own code

    Step back through every instruction and watch exactly what happened, one line at a time.

  • Help, not answers

    Ask Jiki anything and get help working it out, rather than the solution pasted in.

  • See what your code did

    Your instructions, playing out in front of you. No guessing what the computer heard.

  • Stretched, Never Stranded

    The next step is always within reach, and always a step up.
